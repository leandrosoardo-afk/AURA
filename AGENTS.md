# Caja Clara V4

Proyecto nuevo que retoma Caja Clara desde la landing. Leé primero `.agent/rules/caja-clara.md` (reglas), `ESPECIFICACION_V4.md` (qué está hecho y cómo) y `DISENO_UI.md` (cómo se ve).

Comandos: `npm install` · `npm run db:crear` · `npm run dev` · `npm test` · `npm run build`.

No toques `~/Proyectos/CajaClara`, `~/Documents/CajaClara_Antigravity` ni las bases `cajaclara` y `cajaclara_test`: son de versiones anteriores.
